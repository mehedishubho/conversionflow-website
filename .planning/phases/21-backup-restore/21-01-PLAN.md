Create directory `src/lib/backup/` and two files.

**File 1: `src/lib/backup/BackupService.ts`**

This class wraps pg_dump for creating SQL backups. Key requirements:
- Import `execFileSync`, `execSync` from "child_process"
- Import `fs` from "fs", `path` from "path"
- Import `db` from "@/lib/db"
- Import `backups` from "@/lib/db/schema"
- Import `createAuditLog` from "@/lib/audit"
- Import `eq`, `desc` from "drizzle-orm"

Export class `BackupService` with these methods:

1. **`checkBinaryAvailability()`** — Static method returning `{ pg_dump: boolean; psql: boolean }`. Uses `execSync("which pg_dump 2>/dev/null || where pg_dump 2>nul", { stdio: "pipe" })` wrapped in try/catch. Same pattern for psql. Returns `{ pg_dump: true/false, psql: true/false }`.

2. **`createBackup(type: "manual" | "scheduled" | "pre_restore", triggeredBy?: string)`** — Async method:
   - Validates DATABASE_URL env var exists. Throws if missing.
   - Checks pg_dump availability via `checkBinaryAvailability()`. Throws with "pg_dump is not installed or not on PATH" if unavailable.
   - Creates `backups/` directory via `fs.mkdirSync("backups", { recursive: true })`.
   - Generates filename: `backup-{YYYYMMDD-HHmmss}-{type}.sql` using current date.
   - Generates filePath: `path.resolve("backups", filename)`.
   - Inserts a `backups` record with status "in_progress", the filename, filePath, type, triggeredBy.
   - Runs `execFileSync("pg_dump", [process.env.DATABASE_URL!, "-f", filePath], { stdio: "pipe", timeout: 300000 })` inside a try/catch.
   - On success: gets file size via `fs.statSync(filePath).size`, updates the backup record status to "completed", fileSizeBytes, completedAt.
   - On failure: updates the backup record status to "failed", errorMessage.
   - Calls `createAuditLog({ action: "admin.backup_created", targetType: "backup", targetId: backup.id, details: { filename, type, size } })`.
   - Returns `{ success: boolean; backupId: string; filename: string; fileSizeBytes: number; error?: string }`.

3. **`deleteBackup(backupId: string)`** — Async method:
   - Queries backups table for the record by id.
   - If file exists at filePath, deletes it via `fs.unlinkSync(filePath)`.
   - Deletes the database record.
   - Calls `createAuditLog({ action: "admin.backup_deleted", targetType: "backup", targetId: backupId })`.

4. **`getBackups(filters?: { type?: string; status?: string; search?: string; sort?: string })`** — Async method:
   - Queries backups table with optional filtering:
     - type filter: `where(eq(backups.type, filters.type))`
     - status filter: `where(eq(backups.status, filters.status))`
     - search: `where(sql`filename ILIKE ${"%" + filters.search + "%"}`)` — import `sql` from drizzle-orm
   - Sort: default `desc(backups.createdAt)`, or if sort is "size_asc" use `asc(backups.fileSizeBytes)`, "size_desc" use `desc(backups.fileSizeBytes)`, "type_asc" use `asc(backups.type)`, "type_desc" use `desc(backups.type)`.
   - Returns array of backup records.

5. **`getBackupById(id: string)`** — Async method:
   - Returns single backup record or null.

6. **`getBackupStats()`** — Async method:
   - Queries count of all backups, last completed backup createdAt, total disk usage (sum of fileSizeBytes).
   - Returns `{ totalBackups: number; lastBackupAt: Date | null; totalDiskUsageBytes: number }`.

**File 2: `src/lib/backup/BackupRotation.ts`**

Export class `BackupRotation` with:

1. **`enforceRetention()`** — Async method:
   - Read `backup_retention_count` from settings table (default 10 if not set).
   - Query all completed backups ordered by `createdAt ASC`.
   - If count > retention limit, delete the oldest ones:

   - Returns `{ deleted: number }`.

Import settings from schema, eq from drizzle-orm, db from "@/lib/db", fs from "fs", createAuditLog from "@/lib/audit".

   - Validates retentionCount is between 1 and 50.
   - Upserts `backup_retention_count` in settings table.
   - Returns `{ success: true }`.
