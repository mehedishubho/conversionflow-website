```typescript
function formatFileSize(bytes: number): string {
  if (bytes === 0) return "0 B";
  const k = 1024;
  const sizes = ["B", "KB", "MB", "GB"];
  const i = Math.floor(Math.log(bytes) / Math.log(k));
  return parseFloat((bytes / Math.pow(k, i)).toFixed(1)) + " " + sizes[i];
}
```

Map `restoreStatus.stage` to which step is active/completed:
- pre_backup: step 0 active, rest pending
- maintenance: step 0-1 completed, step 2 active
- dropping: step 0-2 completed, step 3 active
- restoring: step 0-3 completed, step 4 active
- verifying: step 0-4 completed, step 5 active
- complete: all completed

**Phase 3: Complete (phase === "complete"):**
Shows "Restore complete" with close button.

**Phase 4: Error (phase === "error"):**
Shows error message with "Rolling back..." or "Rollback failed" indicator, plus close button.

**handleStartRestore:**
1. Sets phase to "progress"
2. Calls `restoreBackupAction(backup.id)` from server actions
3. Starts polling: `setInterval` every 2000ms calling `fetch("/api/admin/backup/restore/status")`
4. On each poll, updates `restoreStatus` state and remaps step indicators
5. When stage is "complete": sets phase to "complete", clears interval
6. When stage is "failed": sets phase to "error" with error message, clears interval
7. On component unmount or onClose: clears interval
