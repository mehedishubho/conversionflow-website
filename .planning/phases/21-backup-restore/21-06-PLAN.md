# Phase 21 Plan 06: Fix Backup Creation — Error Handling & Binary Warning

## Gap

**Test 3 — Create Manual Backup:** Clicking "Create Backup" does nothing. The server action returns `success: false` (likely because `pg_dump` is not on PATH), but the client silently ignores the error.

## Root Cause

Two-layer bug in `BackupDashboard.tsx`:

1. **Line 148:** `handleCreateBackup` only handles `result.success === true`. When false, the error is silently skipped — no toast, no error state, no visual feedback.
2. **Line 44:** `dashboardData.binaryAvailability` is already fetched as a prop but never rendered. Admin has no way to know if `pg_dump` is available before clicking.

## Fix Plan

### Task 1: Add error handling to handleCreateBackup

**File:** `src/components/admin/BackupDashboard.tsx`

- Add `createError` state: `const [createError, setCreateError] = useState<string | null>(null);`
- In `handleCreateBackup`:
  - Clear error on start: `setCreateError(null);`
  - Handle failure: `if (!result.success) { setCreateError(result.error || "Backup creation failed."); return; }`
  - In catch: `setCreateError("An unexpected error occurred.");`
- Render error alert below the Create Backup button when `createError` is set

### Task 2: Add binary availability warning banner

**File:** `src/components/admin/BackupDashboard.tsx`

- Check `dashboardData.binaryAvailability.pg_dump` and `dashboardData.binaryAvailability.psql`
- Show a warning banner above the KPI cards when either is unavailable:
  - "pg_dump is not available on this server. Backups cannot be created until PostgreSQL client tools are installed."
  - Similar for psql: "psql is not available. Restore operations will not work."
- Disable the Create Backup button when `pg_dump` is unavailable
- Disable restore actions in BackupTable when `psql` is unavailable (pass prop)

## Acceptance Criteria

- [ ] Clicking Create Backup when pg_dump is missing shows a visible error message (not silent)
- [ ] Warning banner appears when pg_dump or psql binaries are unavailable
- [ ] Create Backup button is disabled when pg_dump is unavailable
- [ ] Error clears when retrying
