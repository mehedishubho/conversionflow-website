Visual mode content generation function `generateRobotsTxt()`:
- Build robots.txt string from visual form fields:
  1. `User-agent: {userAgent}`
  2. For each allow path: `Allow: {path}`
  3. For each disallow path: `Disallow: {path}`
  4. If crawlDelay set: `Crawl-delay: {value}`
  5. For each blocked AI bot (bots[key] === false): add `User-agent: {key}\nDisallow: /`
  6. `Sitemap: {sitemapUrl}`
- Return the generated string

- "block_ai": allowPaths="/", disallowPaths="", all bots blocked (bots all false)
- "block_all": allowPaths="", disallowPaths="/", all bots allowed (blocking via global disallow)
- "custom": no changes (user configures manually)
- When preset selected, update visual mode state and bots state accordingly
