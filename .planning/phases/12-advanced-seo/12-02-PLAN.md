**llms.txt route handler** (`src/app/llms.txt/route.ts`):
Per D-04: Auto-generate from site data following AnswerDotAI llms.txt specification.
1. Export `async function GET()`.
2. Import `pageSeo` from `@/lib/seo.ts` and `getSeoSettings` (or read settings directly).
3. Read `seo_llms_txt_custom` from settings for any custom additions.
4. Build llms.txt content:
   - H1: `# ConversionFlow`
   - Blockquote summary: `> Commerce tracking, courier automation, COD fraud protection, and analytics for WooCommerce stores.`
   - H2: `## Product` with links from pageSeo.features
   - H2: `## Pricing` with link from pageSeo.pricing
   - H2: `## Documentation` with link from pageSeo.docs
   - H2: `## Support` with link from pageSeo.support
   - H2: `## Optional` with changelog and FAQ links
   - If custom content is set, append it at the end.
5. Return `new Response(content, { headers: { "Content-Type": "text/plain; charset=utf-8" } })`.
6. Wrap in try/catch -- on failure, return a minimal llms.txt with just the site name.
7. NOTE: The proxy.ts matcher excludes URLs with dots (`pathname.includes('.')`), so /llms.txt bypasses the proxy and goes directly to this route handler. This is correct behavior.
