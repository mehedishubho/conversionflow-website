**File 1: `src/modules/licensing/application/services/SemverCompare.ts`**
A simple semver comparison utility -- no npm package needed. Export two functions:
```typescript
export function compareSemver(a: string, b: string): number
```
Parse version strings into `[major, minor, patch]` (strip prerelease suffix after `-`), compare numerically. Returns positive if a > b, negative if a < b, 0 if equal.

```typescript
export function hasUpdate(installedVersion: string, latestVersion: string): boolean
```
Returns `compareSemver(latestVersion, installedVersion) > 0`.

**File 2: `src/modules/licensing/application/services/DownloadTokenService.ts`**
Per D-13, D-14. HMAC-SHA256 signed download tokens with 2-hour expiry.

- Secret: `process.env.DOWNLOAD_SIGNING_SECRET` with fallback to `crypto.randomBytes(32).toString("hex")` (log warning if fallback used)
- `static generateDownloadUrl(baseUrl: string, licenseId: string, versionId: string): string`
  - expires = `Math.floor(Date.now() / 1000) + 7200` (2 hours per D-14)
  - payload = `${licenseId}:${versionId}:${expires}`
  - signature = `crypto.createHmac("sha256", secret).update(payload).digest("hex")`
  - return `${baseUrl}/api/v1/update/download?token=${payload}:${signature}`
- `static verifyToken(token: string): { licenseId: string; versionId: string; expires: number } | null`
  - Split token by `:`, expect 4 parts
  - Parse expires, check `Date.now() / 1000 > expires` (return null if expired)
  - Reconstruct HMAC, compare with `crypto.timingSafeEqual`
  - Return parsed components or null

**File 3: `src/modules/licensing/application/commands/UpdateCheckHandler.ts`**
Per D-08, D-09, D-12. WordPress-compatible update check.

Input interface: `{ licenseKey: string; domain: string; apiToken: string; installedVersion: string; productSlug: string }`

Flow:
1. Parse license key via `LicenseKey.create()` (return `UPDATE_NOT_AVAILABLE` on failure)
2. Normalize domain via `Domain.create()` (return `UPDATE_NOT_AVAILABLE` on failure)
3. Look up license via `LicenseRepository.findByKey(key.value)` -- return not available if null
4. Validate API token via `ApiTokenGenerator.validate()` -- return not available if mismatch
5. Check license status is not "revoked" or "suspended" -- return not available
6. If `license.expiresAt` is past and not in grace period -- return not available
7. Find product by `pluginSlug` from DB: `db.select().from(products).where(eq(products.pluginSlug, input.productSlug)).limit(1)` -- return not available if not found or product.id !== license.productId
8. Find latest stable version: `db.select().from(productVersions).where(and(eq(productVersions.productId, product.id), eq(productVersions.status, "stable"))).orderBy(desc(productVersions.createdAt)).limit(1)` -- per D-12 only stable versions
9. Compare installed_version vs latest version using `hasUpdate()` -- return not available if no newer version
10. Get `platform_url` from settings: `db.select().from(settings).where(eq(settings.key, "platform_url")).limit(1)` -- fallback to empty string
11. Generate signed download URL via `DownloadTokenService.generateDownloadUrl(platformUrl, license.id, latestVersion.id)`
12. Build WordPress-compatible response per D-08:
    ```typescript
    {
      slug: product.pluginSlug,
      new_version: latestVersion.version,
      url: `${platformUrl}/admin/products/${product.id}`,
      package: signedDownloadUrl,
      download_url: signedDownloadUrl,
      last_updated: latestVersion.releasedAt?.toISOString() ?? null,
      sections: {
        description: product.description ?? "",
        changelog: latestVersion.changelog ?? "",
        installation: "Upload the ZIP file via Plugins > Add New > Upload Plugin in your WordPress admin panel.",
      },
      requires: "5.0",
      tested: "6.5",
      requires_php: "7.4",
    }
    ```
13. Log to update_logs: insert record with action "check"
14. Return the response

Define a constant `UPDATE_NOT_AVAILABLE = { update_available: false }` for all error paths (same security approach as INVALID_RESPONSE in validate).
