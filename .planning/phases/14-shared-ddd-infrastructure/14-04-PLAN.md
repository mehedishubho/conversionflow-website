# Plan 14-04: Shared Value Objects (LicenseKey, Money, Email, Domain)

<objective>
Create four immutable value objects (LicenseKey, Money, Email, Domain) in `src/shared/domain/valueObjects/` following DDD patterns with private constructors, static factory methods, validation, equality, and serialization using class-transformer.
</objective>

## Decisions Locked (from RESEARCH.md)
- D-24: All four value objects created in Phase 14
- D-25: Immutable classes with private constructor, static `create()` factory method
- D-26: Validation throws on invalid input — fail fast
- D-27: Serialization uses `class-transformer` library (already installed)
- D-28: Reference equality (`===`) for comparison
- D-29: Rich domain model — VOs have both data and behavior

## Tasks

### Task 1: Create LicenseKey Value Object
**Files:** `src/shared/domain/valueObjects/LicenseKey.ts`
**Must have:**
- Private constructor, `static create(input: string): LicenseKey`
- Validates format: uppercase alphanumeric, no ambiguous chars (0/O, 1/I/L)
- Strips hyphens/spaces, normalizes to uppercase
- `get value(): string` getter
- `get formatted(): string` — returns segmented format (e.g., `ABCD-1234-EFGH`)
- `equals(other: LicenseKey): boolean` using `===`
- `toJSON()` / static `fromJSON()` for serialization
- `Object.freeze(this)` in constructor

### Task 2: Create Money Value Object
**Files:** `src/shared/domain/valueObjects/Money.ts`
**Must have:**
- Private constructor, `static create(amount: number, currency: string = 'BDT'): Money`
- Validates: non-negative amount, valid currency code
- Supports BDT and USD as primary currencies
- `get amount(): number`, `get currency(): string` getters
- `add(other: Money): Money`, `subtract(other: Money): Money` — currency-safe arithmetic
- `multiply(factor: number): Money`
- `format(): string` — locale-aware formatting (৳ for BDT, $ for USD)
- `equals()` using `===`, `toJSON()` / `fromJSON()`
- `Object.freeze(this)` in constructor

### Task 3: Create Email Value Object
**Files:** `src/shared/domain/valueObjects/Email.ts`
**Must have:**
- Private constructor, `static create(input: string): Email`
- Validates RFC 5322 format via regex
- Normalizes to lowercase, trims whitespace
- `get value(): string`, `get domain(): string` getters
- `equals()`, `toJSON()` / `fromJSON()`
- `Object.freeze(this)` in constructor

### Task 4: Create Domain Value Object
**Files:** `src/shared/domain/valueObjects/Domain.ts`
**Must have:**
- Private constructor, `static create(input: string): Domain`
- Normalizes: strips protocol (https://), www prefix, trailing slashes, lowercase
- Validates: valid hostname format, no protocol/paths
- `get value(): string` getter
- `get tld(): string` — extracts top-level domain
- `isSubdomain(): boolean`
- `equals()`, `toJSON()` / `fromJSON()`
- `Object.freeze(this)` in constructor

### Task 5: Create barrel export and index
**Files:** `src/shared/domain/valueObjects/index.ts`, `src/shared/domain/index.ts`
**Must have:**
- Barrel export for all value objects
- Domain-level index re-exporting value objects
- Verify imports work via `@/shared/domain/valueObjects` path alias
