     - Count badge: `<Badge color="light" size="sm">Showing {filtered.length} of {total} errors</Badge>`
   - Table with columns: URL, Referrer, Hits, Last Seen
   - If `errors` array is empty (no 404 errors at all):
     - Show a centered empty state: green `Badge` with `<CheckCircle className="w-3 h-3" />` startIcon + "No 404 errors recorded"
     - Below: `text-sm text-gray-400 mt-2` "404 errors will appear here when visitors hit non-existent pages."
   - If `filtered` array is empty (search matched nothing):
     - Show: `text-sm text-gray-400 py-4` "No errors match your search."
   - Otherwise render table:
     - Table: `w-full text-sm`
     - Header: `border-b border-gray-200 dark:border-gray-700`, cells: `px-4 py-3 text-left text-xs font-medium text-gray-500 dark:text-gray-400 uppercase tracking-wider`
