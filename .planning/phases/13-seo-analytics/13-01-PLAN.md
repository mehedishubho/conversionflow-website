```typescript
export const seo404Errors = pgTable(
  "seo_404_errors",
  {
    id: uuid("id").defaultRandom().primaryKey(),
    url: text("url").notNull(),
    referrer: text("referrer"),
    hitCount: integer("hit_count").default(1).notNull(),
    lastSeenAt: timestamp("last_seen_at").notNull().defaultNow(),
    createdAt: timestamp("created_at").notNull().defaultNow(),
  },
  (table) => [
    unique("seo_404_errors_url_unique").on(table.url),
    index("seo_404_errors_last_seen_idx").on(table.lastSeenAt),
  ]
);
```

IMPORTANT: The `unique` constraint on `url` is REQUIRED for the `onConflictDoUpdate` upsert in `log404Error` (Task 2). Without it, the upsert cannot identify which row to update.

Imports needed: `uuid`, `text`, `integer`, `timestamp`, `index` are all already imported at the top of schema.ts. Add `unique` to the import from `"drizzle-orm/pg-core"` if it is not already imported.

Add the following 3 exported server actions at the end of the file:

1. **`get404Errors(limit = 50)`** -- Returns `{ errors: Array<{id, url, referrer, hitCount, lastSeenAt, createdAt}>, total: number }`:
   - Call `await requireAdmin()` first
   - Query `seo404Errors` ordered by `desc(seo404Errors.lastSeenAt)` with the provided limit

   - Return typed result object

2. **`getSitemapHealth()`** -- Returns `{ totalUrls: number, lastGenerated: string, xmlValid: boolean, sitemapEnabled: boolean }`:
   - Call `await requireAdmin()` first
   - Dynamic import the sitemap function: `const sitemapModule = await import("@/app/sitemap"); const sitemapFn = sitemapModule.default;`
   - Call `await sitemapFn()` to get entries array
   - Query settings table for `"seo_sitemap_enabled"` and `"seo_sitemap_last_generated"` keys
   - Return `{ totalUrls: entries.length, lastGenerated: lastGenRow?.value ?? "Never", xmlValid: Array.isArray(entries) && entries.length >= 0, sitemapEnabled: enabledRow?.value !== "false" }`
   - Wrap entire function body in try/catch returning fallback `{ totalUrls: 0, lastGenerated: "Never", xmlValid: false, sitemapEnabled: false }` on error

3. **`log404Error(url: string, referrer: string | null)`** -- Returns `{ success: boolean }`:
   - NO `requireAdmin()` call -- this is called from the public not-found page
   - Validate `url` is a non-empty string, sanitize: `url.replace(/<[^>]*>/g, "")`
   - Validate `referrer` if provided (same sanitization)
   - Use Drizzle's `onConflictDoUpdate` to upsert by URL:
     ```typescript
     await db.insert(seo404Errors)
       .values({ url: sanitizedUrl, referrer: sanitizedReferrer })
       .onConflictDoUpdate({
         target: seo404Errors.url,
         set: {
           hitCount: sql`${seo404Errors.hitCount} + 1`,
           lastSeenAt: new Date(),
           referrer: sanitizedReferrer ?? sql`COALESCE(${seo404Errors.referrer}, '')`,
         },
       });
     ```
   - Wrap in try/catch, return `{ success: false }` on error (never throw from a 404 logger)

| Public not-found page -> server action | Untrusted: any visitor hitting a 404 triggers log404Error with arbitrary URL/referrer values |
| Admin analytics -> DB queries | Trusted: requireAdmin() guards all read actions |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-01 | Tampering | log404Error url/referrer params | mitigate | Sanitize input: strip HTML tags with regex `/<[^>]*>/g`, validate non-empty string, use Drizzle parameterized queries (never raw SQL) |
| T-13-02 | Denial of Service | seo_404_errors table growth | mitigate | Unique constraint on url + hit_count aggregation prevents unlimited row growth; limit=50 on queries prevents large result sets |
| T-13-03 | Spoofing | Analytics dashboard access | mitigate | requireAdmin() on get404Errors, getSitemapHealth -- same pattern as all admin actions |
| T-13-04 | Elevation | log404Error without auth check | accept | Public function only writes to seo_404_errors table, cannot read or modify any other data, cannot access admin functions |
