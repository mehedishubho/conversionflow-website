# Phase 13 Discussion Log

**Phase:** 13 — SEO Analytics Dashboard
**Date:** 2026-05-21

## Gray Areas Discussed

### 1. Data Source Strategy

**Question:** Google Search Console API is deferred to v4. Where does keyword ranking, CTR, and impressions data come from?

**Options presented:**
- Honest placeholders (like Phase 12 CWV cards)
- Mock demo data with banner
- GA4-only + placeholders

**Decision:** Honest placeholders — show UI layout with "--" values and notes about connecting Search Console API. GA4 data (top pages, pageviews) stays real.

**Rationale:** Follows Phase 12 D-06/D-07 precedent. Honest about what's available. Clear activation path for v4.

### 2. 404 Error Tracking

**Question:** How should 404 errors be tracked?

**Options presented:**
- DB table + proxy.ts logging
- GA4 404 report only
- Skip for now

**Decision:** DB table + proxy.ts logging. Create `seo_404_errors` table. Log unmatched routes in proxy.ts.

**Rationale:** Real data without external API dependency. proxy.ts is the natural place for route detection. Provides actionable 404 data for redirect management.

### 3. Time Ranges

**Question:** What time range options for charts?

**Options presented:**
- 7d, 30d, 90d, Year
- 7d, 14d, 30d, 90d

**Decision:** 7d, 30d, 90d, Year — matches existing DateRangeSelector pattern.

### 4. Sitemap Health

**Question:** Local analysis or placeholder cards?

**Options presented:**
- Local analysis of generated sitemap.xml
- Placeholder cards

**Decision:** Local analysis — read sitemap, count URLs, check validity, show last generated date.

**Rationale:** Sitemap is generated by the app (Phase 10). Local analysis provides real health data without any API dependency.

### 5. Page Layout

**Question:** How to structure the 3 plan sections?

**Options presented:**
- Single scrollable page
- Tabbed layout
- Sub-route pages

**Decision:** Single scrollable page at `/admin/settings/seo/analytics`.

**Rationale:** Already a single placeholder page. 3 sections flow naturally as dashboard. Consistent with other SEO sub-pages. Simpler than tabs/sub-routes.

## No Gray Areas Skipped

All identified gray areas were discussed. No scope creep occurred.
