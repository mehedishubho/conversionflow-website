1. **Create `src/app/(admin)/actions/admin-license-analytics.ts`** ("use server"):
- `requireAdmin()` guard following exact pattern from `admin-settings.ts`
- `getLicenseAnalyticsData()`:
  - Queries `licenseAnalyticsCache` for latest snapshot (using `AnalyticsCacheRepository.getLatestSnapshot()`)
  - If no snapshot exists, returns zeroed KPI data with `cacheEmpty: true` flag
  - Queries `licenseActivations` with geo column for geo table data
  - Returns `{ kpis, geo, cacheEmpty }` typed object
- `getLicenseChartData(range: "7d" | "30d" | "90d" | "year")`:
  - Queries `licenses` table directly with `created_at` range filter (D-06: trend data from live table)
  - Groups by date and status for trend chart series
  - Groups by `productId` and `plan` for product breakdown
  - Returns `{ categories, trendSeries, productSeries }`

2. **Create `src/app/(admin)/admin/licenses/analytics/page.tsx`** (server component):
- Follows exact pattern from `src/app/(admin)/admin/analytics/page.tsx`
- `export const dynamic = "force-dynamic"`
- Auth check: session, redirect if no session, role check (admin/super_admin), redirect if unauthorized
- Calls `getLicenseAnalyticsData()` for KPI and geo data
- Calls `getLicenseChartData("30d")` for initial chart data with 30d default
- Renders `<PageBreadcrumb pageTitle="License Analytics" />` then `<LicenseAnalyticsClient initialKPIs={...} initialCharts={...} initialGeo={...} initialRange="30d" />`
- Below KPI grid: `<p className="text-xs text-gray-400 mt-2 mb-6">Data refreshed daily at 1:00 AM UTC</p>`

3. **Create `src/components/admin/analytics/LicenseAnalyticsClient.tsx`** ("use client"):
- Props: `initialKPIs`, `initialCharts`, `initialGeo`, `initialRange`
- State: `range` (initialized from `initialRange`), `chartData` (initialized from `initialCharts`)
- Renders in order:
  1. `<DateRangeSelector activeRange={range} onRangeChange={handleRangeChange} />`
