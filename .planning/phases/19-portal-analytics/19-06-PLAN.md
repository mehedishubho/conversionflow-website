    **Part A: Create transfer settings page at /admin/settings/transfer/page.tsx**

    Create `src/app/(admin)/admin/settings/transfer/page.tsx` following the exact pattern of `src/app/(admin)/admin/settings/subscription/page.tsx`:

    ```typescript
    import { getTransferSettings } from "@/app/(admin)/actions/admin-settings";
    import TransferSettingsForm from "@/components/admin/TransferSettingsForm";
    import PageBreadcrumb from "@/components/common/PageBreadCrumb";

    export const dynamic = "force-dynamic";

    export default async function TransferSettingsPage() {
      const settings = await getTransferSettings();

      return (
        <div>
          <PageBreadcrumb
            pageTitle="Transfer Settings"
            basePath="/admin/settings"
          />
          <TransferSettingsForm
            initialData={{
              maxTransfersPerMonth: settings.maxTransfersPerMonth,
            }}
          />
        </div>
      );
    }
    ```

    Note: The auth guard is handled by the parent `layout.tsx` (which calls `requireAdmin()`), so the page itself does not need its own auth check. This follows the same pattern as the subscription settings page.

    **Part B: Create TransferSettingsForm component**

    Create `src/components/admin/TransferSettingsForm.tsx` following the exact pattern of `src/components/admin/SubscriptionSettingsForm.tsx`:

    1. `"use client"` directive at top.
    2. Imports: `React, { useState, useTransition }` from "react", `ComponentCard` from `@/components/common/ComponentCard`, `InputField` from `@/components/form/input/InputField`, `Button` from `@/components/ui/button/Button`, `saveTransferSettings` from `@/app/(admin)/actions/admin-settings`.
    3. Props interface:
       ```typescript
       interface TransferSettingsFormProps {
         initialData: {
           maxTransfersPerMonth: number;
         };
       }
       ```
    4. Component body:
       - `useState` for `maxTransfersPerMonth` initialized from `initialData.maxTransfersPerMonth`
       - `useTransition` for `isPending` + `startTransition`
       - `useState` for `message` of type `{ type: "success" | "error"; text: string } | null`
    5. `handleSubmit(formData: FormData)` function:
       - Parse `maxTransfersPerMonth` from `formData.get("maxTransfersPerMonth")`
       - Client-side validation: must be integer between 1 and 12
       - If invalid, set error message: "Transfer limit must be between 1 and 12 per month."
       - If valid, call `saveTransferSettings({ maxTransfersPerMonth: parsedValue })` in `startTransition`
       - On `result.error`, show error. On success, show "Transfer settings saved successfully."
    6. JSX structure (inside `<ComponentCard title="License Transfer Settings">`):
       - Form with `action={handleSubmit}` and `className="space-y-6"`
       - Message display div (same styling as SubscriptionSettingsForm)
       - InputField for max transfers:
         - `label="Maximum Transfers Per Month"`
         - `name="maxTransfersPerMonth"`
         - `type="number"`
         - `placeholder="1"`
         - `value={String(maxTransfersPerMonth)}`
         - `onChange` to update state with `parseInt(e.target.value, 10)`
         - `min={1}`, `max={12}`
       - Help text below input: `"Maximum number of times a license can be transferred per calendar month (1-12). Default: 1. Each transfer clears all domain activations and reassigns ownership."`
       - Submit button aligned right: `<Button type="submit" disabled={isPending}>{isPending ? "Saving..." : "Save Settings"}</Button>`
