### Pre-existing Design System (from prior phases)

This phase does NOT introduce a new design system. It extends the existing TailAdmin-based admin dashboard and customer portal design system established in v2.0-v2.1. All tokens, colors, and component patterns are already defined in `src/app/globals.css` and the existing component library.

**Key token sources:**
- `:root` / `.dark` CSS custom properties in `globals.css` for marketing site

- Custom `@utility` definitions for menu items, scrollbars, etc.

## Interaction Patterns

### Admin Analytics Page

1. **Page load**: Server component fetches KPI data from `license_analytics_cache` table, chart data from `licenses` table, geo data from `license_activations` with `geo` column. Passes to `LicenseAnalyticsClient` client component.
2. **Date range change**: Client calls server action with new range, updates chart data only (KPIs remain from cache, always "current snapshot").
3. **Chart hover**: ApexCharts tooltip shows series value + date, styled per existing `RevenueChart.tsx` pattern.
4. **Geo table**: Static table sorted by activation count descending. No interactive sorting needed (follows `GeographicDistribution.tsx` simplified table pattern).

### Customer Transfer Flow

1. **Initiate**: Customer clicks "Generate Transfer Code" on license detail page -> confirmation modal -> server action generates `CF-XFER-XXXXXX` code -> code displayed in monospace box with copy button.
2. **Share**: Customer copies code manually (no in-app sharing mechanism -- WhatsApp/email out of band).
3. **Claim**: Recipient enters code on their license page (`/dashboard/licenses` with code input) -> server action validates code, checks recipient account, reassigns license in transaction -> success toast/message.
4. **History**: Both sender and recipient see transfer entries in the "Transfer History" section on the license detail page.

### Customer Subscription Visibility

1. **Lifetime license**: Shows green "Lifetime License" badge, "This license does not expire." text, no Renew CTA.
2. **Active subscription**: Shows status badge, expiry date, "X days remaining", Renew CTA button linking to `/pricing`.
3. **Expiring soon (<30 days)**: Shows warning-colored days remaining text, prominent Renew CTA.
4. **Grace period**: Shows warning "Grace Period" badge, days remaining, Renew CTA.
5. **Expired**: Shows "Expired on [date]" text, no active Renew CTA (still links to `/pricing`).
