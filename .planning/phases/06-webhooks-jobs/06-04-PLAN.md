**1. Create `src/lib/piracy-detection.ts`** -- Pure function library for piracy trigger evaluation.

Imports: `ActivationDomain` type from `@/lib/webhook-types`.

Export `PiracyFlag` interface:
```typescript
export interface PiracyFlag {
  type: "activation_limit_exceeded" | "rapid_domain_burst" | "geo_anomaly" | "cross_site_match";
  severity: "low" | "medium" | "high";
  description: string;
  detectedAt: Date;
}
```

Export `evaluatePiracyTriggers` function:
```typescript
export function evaluatePiracyTriggers(params: {
  currentActivations: number;
  maxActivations: number;
  domains: ActivationDomain[];
  licenseKey: string;
}): PiracyFlag[]
```

Four trigger checks per D-04:

1. **Activation limit exceeded** (severity: "high"): `currentActivations > maxActivations` AND `maxActivations > 0`. Description: `"{currentActivations} activations exceed plan limit of {maxActivations}"`.

2. **Rapid domain activation burst** (severity: "medium"): 5+ domains with `activatedAt` within last 24 hours. Description: `"{count} domains activated in 24 hours"`.

3. **Geographic anomaly** (severity: "low"): 3+ unique countries across all domains. Description: `"Activations from {count} different countries"`.

4. **Cross-site match** is NOT checked in this pure function -- it requires querying OTHER licenses. Document this: `// Cross-site match detection is done at server action level, not in this pure function`. Add a separate exported function:
```typescript
export async function checkCrossSiteMatch(
  db: any, // Drizzle instance
  domains: ActivationDomain[],
  currentLicenseId: string
): Promise<PiracyFlag | null>
```
This queries other active licenses where their `activationDomains` jsonb overlaps with the given domains. If same domain appears on 2+ unrelated licenses (different userId), flag it as `"cross_site_match"` with severity `"high"`. Use PostgreSQL `?|` jsonb operator or filter in JS. Description: `"Domain {domain} also activated on {count} other licenses"`.

**2. Modify `src/app/(admin)/actions/admin-licenses.ts`** -- Add new exports.

Read the current file first, then ADD these new functions (do NOT remove existing exports):

**`getLicenseDetail(id: string)`** async function:
- `requireAdmin()` guard
- Query license by id: `db.select().from(licenses).where(eq(licenses.id, id)).limit(1)`
- If not found, return `{ error: "License not found. It may have been removed or the ID is invalid." }`
- Join with user table to get userName
- Join with orders table to get centralOrderId, order status
- Cast `activationDomains` as `unknown as ActivationDomain[]` (per Drizzle jsonb pattern from Phase 3)
- Run `evaluatePiracyTriggers` on the license data
- Run `checkCrossSiteMatch` on the domains
- Combine all flags into `piracyFlags` array
- Return `{ license: { ...licenseData, userName, centralOrderId, piracyFlags } }`

**`dismissPiracyFlag(licenseId: string, flagType: string)`** async function:
- `requireAdmin()` guard
- Audit log: `"piracy.flag_dismissed"` with details `{ licenseId, flagType, dismissedBy: userId }`
- Return `{ success: true }`
- No database change -- dismissal is logged via audit trail (the flag is re-evaluated on next page load from live data)

**`suspendLicense(licenseId: string, reason: string)`** async function:
- `requireAdmin()` guard
- Update license status to `"suspended"`: `db.update(licenses).set({ status: "suspended" }).where(eq(licenses.id, licenseId))`
- Audit log: `"license.status_changed"` with details `{ from: previousStatus, to: "suspended", reason, suspendedBy: userId }`
- Return `{ success: true }`

**`revokeLicense(licenseId: string, reason: string)`** async function:
- `requireAdmin()` guard
- Update license status to `"revoked"`: `db.update(licenses).set({ status: "revoked" }).where(eq(licenses.id, licenseId))`
- Audit log: `"license.status_changed"` with details `{ from: previousStatus, to: "revoked", reason, revokedBy: userId }`
- Return `{ success: true }`

**`getFlaggedLicenses()`** async function:
- `requireAdmin()` guard
- Get all active licenses with their activationDomains
- For each, run `evaluatePiracyTriggers` and `checkCrossSiteMatch`
- Filter to only those with flags (non-empty array)
- Return `{ licenseId, licenseKey, userName, plan, status, flags }[]`
