## Existing UI Patterns (MUST follow)

Phase 6 extends the Phase 5 admin dashboard. All new pages and components MUST match these established patterns:

### Layout
- **Page wrapper**: `PageBreadcrumb` at top, then content sections
- **Card wrapper**: `ComponentCard` with title + desc props, rounded-2xl border with light/dark variants
- **Grid**: `grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-4` for KPIs, `grid grid-cols-1 lg:grid-cols-2` for detail cards
- **Admin auth guard**: `auth.api.getSession()` + role check + `redirect()` pattern (server component)

### KPI Cards
- **Pattern**: `DashboardKPIs.tsx` — grid of 4 cards, each with icon in 12x12 rounded-xl bg, label in `text-sm text-gray-500`, value in `text-title-sm font-bold text-gray-800 dark:text-white/90`, trend badge using `Badge` component with ArrowUp/ArrowDown icons
- **Card styling**: `rounded-2xl border border-gray-200 bg-white dark:border-gray-800 dark:bg-white/[0.03] px-6 py-5`
- **Icon container**: `flex items-center justify-center w-12 h-12 bg-gray-100 rounded-xl dark:bg-gray-800`

### Tables
- **Pattern**: Standard `<table className="w-full text-sm">` inside `overflow-x-auto`
- **Header**: `border-b border-gray-200 dark:border-gray-700`, cells `text-left py-3 px-4 font-medium text-gray-500 dark:text-gray-400`
- **Rows**: `border-b border-gray-100 dark:border-gray-800 last:border-0`
- **Empty state**: `<td colSpan={N} className="text-center py-8 text-gray-400 dark:text-gray-500">`
- **Status badges**: Badge component with `variant="light"` and color from status map

### Charts
- **Pattern**: ApexCharts with `dynamic(() => import("react-apexcharts"), { ssr: false })`
- **Wrapper**: `max-w-full overflow-x-auto custom-scrollbar` with `min-w-[600px]` inner
- **Options**: DM Sans font family, toolbar hidden, dataLabels disabled, 12px axis label font

### Filters/Tabs
- **Pattern**: `DateRangeSelector` — flex-wrap gap-2, pill buttons with active state `bg-brand-50 text-brand-500 border-brand-500` and inactive `bg-white text-gray-500 border-gray-200`
- **Active**: `px-4 py-2 text-sm font-medium rounded-lg border transition-colors`

### Navigation
- **Pattern**: `adminNavItems` in `src/data/dashboard-nav.ts` with `NavItem` type (name, icon, path, optional subItems)
- **Sidebar**: Uses `menu-item` / `menu-dropdown-item` utilities from dashboard.css

## Interaction Contracts

### Tab/Filter Navigation
- **Component**: Reuse `DateRangeSelector` pill pattern but with custom labels
- **Active state**: `bg-brand-50 text-brand-500 border-brand-500`
- **Inactive state**: `bg-white text-gray-500 border-gray-200`
- **Transition**: `transition-colors` on hover/click
- **Data loading**: `useTransition` with server action call, no loading spinner (optimistic UI)

### Piracy Flag Actions
- **Dismiss**: Button with `btn-outline` class. Confirmation via browser `confirm()` dialog (lightweight, matches existing pattern). Logs audit event.
- **Suspend**: Button with `btn-primary` class, red variant. Confirmation dialog required. Changes license status to `suspended`. Logs audit event.
- **Revoke**: Button with destructive styling (red bg). Confirmation dialog required. Changes license status to `revoked`. Logs audit event.
- All actions call server actions with `requireAdmin()` guard. All actions log via `createAuditLog()`.

### Sync Retry
- **Trigger**: "Retry Sync" button per row in Sync Failures tab, or per license in detail page
- **Feedback**: Button shows loading state via `useTransition` isPending. On success, row updates. On failure, error toast/message.
- **Action**: Server action enqueues a `single_retry` job to `licenseSyncQueue`

### Chart Interaction
- **Plan Distribution**: ApexCharts donut chart. Hover shows tooltip with plan name + count + percentage. Click legend to toggle segments. Dark mode colors: lighter segment variants.
- **Responsive**: Chart container uses `max-w-full overflow-x-auto custom-scrollbar` with `min-w-[400px]` inner for donut (narrower than bar/area charts).

### License Detail Navigation
- **Entry**: "View" link in license table row. Navigates to `/admin/licenses/[id]`.
- **Back**: "Back to Licenses" link at top of detail page, matching pattern from user detail page.
