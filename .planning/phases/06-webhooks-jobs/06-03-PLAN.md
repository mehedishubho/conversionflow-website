**1. `requireAdmin()` guard** -- Copy the same pattern: `auth.api.getSession()`, check `session.user.role` is `"admin"` or `"super_admin"`, redirect if not.

**2. Types:**
```typescript
export interface LicenseKPIs {
  total: number;
  active: number;
  expired: number;
  revoked: number;
  suspended: number;
  expiringSoon7d: number;
  expiringSoon30d: number;
  activationRate: number; // percentage of licenses with currentActivations > 0
}

export interface PlanDistribution {
  plan: string;
  count: number;
}

export interface LicenseRow {
  id: string;
  licenseKey: string;
  userName: string | null;
  plan: string;
  status: string;
  currentActivations: number;
  maxActivations: number;
  createdAt: Date;
  expiresAt: Date | null;
  centralLicenseId: string | null;
  orderId: string | null;
  syncError: string | null;
}
```

**3. `getLicenseKPIs()` async function:**
- Call `requireAdmin()`
- Single query using `sql<number>` with PostgreSQL `COUNT(*) FILTER (WHERE ...)` to get all status counts in one round trip:
  - total: `COUNT(*)`
  - active: `COUNT(*) FILTER (WHERE status = 'active')`
  - expired: `COUNT(*) FILTER (WHERE status = 'expired')`
  - revoked: `COUNT(*) FILTER (WHERE status = 'revoked')`
  - suspended: `COUNT(*) FILTER (WHERE status = 'suspended')`
  - expiringSoon7d: `COUNT(*) FILTER (WHERE expiresAt <= ${sevenDaysFromNow} AND expiresAt > ${now} AND status = 'active')`
  - expiringSoon30d: `COUNT(*) FILTER (WHERE expiresAt <= ${thirtyDaysFromNow} AND expiresAt > ${sevenDaysFromNow} AND status = 'active')`
  - activationRate: Calculate as `(total - unused) / total * 100` where unused = `COUNT(*) FILTER (WHERE currentActivations = 0)`. Guard division by zero.
- Return `LicenseKPIs` object

**4. `getPlanDistribution()` async function:**
- Call `requireAdmin()`
- Query: `SELECT plan, COUNT(*) FROM licenses GROUP BY plan ORDER BY count DESC`
- Return `PlanDistribution[]`

**5. `getLicenses(filter?: "all" | "flagged" | "sync_failures")` async function:**
- Call `requireAdmin()`
- Build query based on filter param:
  - `"all"` (default): All licenses, ordered by `createdAt DESC`
  - `"sync_failures"`: Licenses where `orders.centralOrderId IS NULL` (join orders, filter where centralOrderId is null). This finds licenses created from completed orders that never got central mapping.
- Return `LicenseRow[]` with leftJoin on user table for userName

**6. `retryLicenseSync(orderId: string)` async function:**
- Call `requireAdmin()`
- Guard: if `licenseSyncQueue` is null, return `{ error: "Job queue not available (Redis not configured)" }`
- Enqueue a single_retry job: `await licenseSyncQueue.add("single-retry", { type: "single_retry", orderId }, { attempts: 3, backoff: { type: "exponential", delay: 5000 } })`
- Audit log: `license.sync_retry` with orderId
- Return `{ success: true }`
