         - If fingerprint differs from lastSmtpConfig OR smtpTransporter is null: create new transporter, cache it
         - Send via transporter.sendMail({ from, to: user.email, subject: template.subject, html: template.html })
      6. If provider === "resend":
         - Use Resend SDK: resend.emails.send({ from: process.env.EMAIL_FROM || "noreply@salesconversionflow.com", to: user.email, subject: template.subject, html: template.html })
