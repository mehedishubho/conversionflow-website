<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin -> Delivery log page | Admin-only page; requires admin role check |
| Admin -> Email settings | SMTP credentials stored in DB; admin-only access to settings page |
| Admin -> Retry notification | Re-triggers sendNotification; could be used for spam if admin is compromised |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-10 | Information Disclosure | SMTP password in getEmailProviderSettings response | mitigate | Do NOT return smtp_pass to client; only use it server-side in sendEmail |
| T-07-11 | Elevation of Privilege | Non-admin accessing notification admin page | mitigate | Server component auth check + role check before rendering |
| T-07-12 | Denial of Service | Admin retrying notifications rapidly | accept | Admin-only action, rate limited by BullMQ worker concurrency |
</threat_model>
