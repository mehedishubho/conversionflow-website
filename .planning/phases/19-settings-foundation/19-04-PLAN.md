<objective>
Fix ERR_TOO_MANY_REDIRECTS when non-admin users access /admin/* routes.

Purpose: The current auth guard redirects unauthorized users to /admin/dashboard, but /admin/dashboard itself requires admin access and redirects back -- creating an infinite loop. This is a systemic bug affecting 31 files across the entire admin section.

Root cause: `requireAdmin()` in auth-guard.ts and all local `requireAdmin()` functions in action files redirect non-admin users to `/admin/dashboard`, which itself calls `requireAdmin()`. The fix is to redirect non-admin users to `/dashboard` (the customer portal) instead, which is their correct destination.

Output: All admin auth guards redirect non-admin users to `/dashboard` (customer portal) instead of `/admin/dashboard`.
</objective>
