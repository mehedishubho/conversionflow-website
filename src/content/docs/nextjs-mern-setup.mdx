# Next.js / MERN Edition Setup

The Next.js / MERN Edition is for headless commerce teams that need server-side event infrastructure, scalable analytics, and developer-controlled tracking architecture.

## Integration Areas

- Server-side purchase and lead events
- Meta CAPI and browser Pixel deduplication
- GA4 and Google Ads conversion routing
- Checkout recovery data capture
- Courier status and delivery outcome events
- Operational dashboards for commerce teams

## Implementation Guidance

Design event payloads around the order lifecycle. Track checkout intent, payment commitment, courier state, and delivery outcome so marketing data reflects operational truth.
