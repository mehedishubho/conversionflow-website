# Laravel Edition Setup

The Laravel Edition is designed for developer-led commerce stacks that need API-ready workflows and deeper customization than a WordPress plugin can provide.

## Integration Areas

- Server-side Meta CAPI events
- Order lifecycle events
- Courier booking and status sync
- Partial payment verification
- Fraud and COD review signals
- Operational analytics dashboards

## Implementation Guidance

Keep event names stable, separate browser and server-side tracking responsibilities, and make courier/payment state changes auditable.
